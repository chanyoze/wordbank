## 2. 빌드/톰캣 트러블슈팅 (실제 겪은 이슈 — 재발 시)

- **`ContextLoaderListener` ClassNotFound** = 배포 `WEB-INF/lib`에 Maven jar 미배포. 근본: `.classpath`의 Maven 컨테이너에 `org.eclipse.jst.component.dependency="/WEB-INF/lib"` 속성 누락 + `${BUILD_TARGET}` 미해결. **해결**: Project > Deployment Assembly에 "Maven Dependencies" 추가 + `BUILD_TARGET=local`(settings.xml 활성 프로파일) + 서버 **Clean → full Publish**.
- **WebSquare Design 뷰에서 탭 그리드 안 보임** = `<w2:content>`에 `style="height:..."` 없어서 접힘. (alwaysDraw 무관.)
- **간헐적 기동 실패**는 대개 WTP publish 타이밍 — Clean+Publish로 안정화.

## 2-1. 📋 배포 선행 DDL — 운영(SKPMIS) 미생성 컬럼 (의도된 상태)

**2026-08-11 SKPMIS 실측.** 승인 모듈·CCTV 관련 컬럼이 운영에 아직 없습니다. **아직 안 만든 것이 의도된 상태**이고(개발 진행 중), 배포 시 DDL을 함께 반영하면 됩니다. 결함이 아니라 **배포 체크리스트 항목**입니다.

다만 DDL 없이 애플리케이션만 올리면 `ORA-00904` 로 화면이 죽으므로, 배포 순서에서 빠지지 않게 아래 목록을 기준으로 삼습니다.

| 테이블 | 없는 컬럼 | 용도 |
|---|---|---|
| `TCC_PROJ_CODE` (293컬럼) | `SFAS_OPT_060_003` | 승인 모듈 사용여부 — 운영엔 `060`·`060_001`·`060_002` 만 존재 |
| `TCC_PROJ_CODE` | `SFAS_OPT_120` | CCTV관제여부 사용여부 |
| `TSF_ASSMNT_RECEIVE` (40컬럼) | `CFM_COMPANY_ID` · `CFM_PROJ_CODE` · `CFM_DEM_SN` · `CFM_STS_CODE` | 승인 모듈 결재 연결키 |
| `TSF_ASSMNT_REGIS` (21컬럼) | 위 4종 동일 | 〃 |
| `TSF_ASSMNT_RECEIVE_DETAIL` · `TSF_ASSMNT_REGIS_DETAIL` (+ `DTDB_` 아카이브 2종) | `CCTV_MON_TF` | CCTV관제여부 |

확인 쿼리 (SKPMIS)

```sql
Select
    a.TABLE_NAME,  -- 테이블명
    a.COLUMN_NAME  -- 컬럼명
From
    USER_TAB_COLUMNS a
Where 1 = 1
And a.TABLE_NAME In ('TSF_ASSMNT_RECEIVE', 'TSF_ASSMNT_REGIS', 'TSF_ASSMNT_RECEIVE_DETAIL', 'TSF_ASSMNT_REGIS_DETAIL', 'TCC_PROJ_CODE')
And a.COLUMN_NAME In ('CFM_COMPANY_ID', 'CFM_PROJ_CODE', 'CFM_DEM_SN', 'CFM_STS_CODE', 'CCTV_MON_TF', 'SFAS_OPT_060_003', 'SFAS_OPT_120')
Order By a.TABLE_NAME, a.COLUMN_NAME
```

> 배포 시점에 0행이면 아직 DDL 미반영입니다. 개발(PMIS4)에는 전부 있어서 **개발 환경 테스트로는 절대 드러나지 않습니다** — 배포 직전에 이 쿼리로 한 번 확인하는 게 유일한 방어선입니다.

## 3. 검증 방식

- 회사 Maven 빌드는 에이전트 환경에서 **불가**. → IDE 진단(컴파일) + XML well-formedness(.NET 파서)로 확인, 런타임은 톰캣 재기동.
- **wqxml 스크립트 JS 문법 검증**: `<script>` 블록만 뽑아 `node --check` (node v24 설치돼 있음). XML well-formed 만으로는 JS 오류가 안 잡히므로 wqxml 수정 후 같이 돌린다.
  ```powershell
  $txt=[IO.File]::ReadAllText($p,[Text.Encoding]::UTF8)
  $m=[regex]::Match($txt,'(?s)<script[^>]*>(.*?)</script>')
  [IO.File]::WriteAllText($tmp,$m.Groups[1].Value,(New-Object Text.UTF8Encoding($false))); node --check $tmp
  ```
- ⚠️ **VSCode 의 wqxml 인라인 JS 진단은 스퓨리어스가 섞인다** — `};` 라인에 *"',' expected"* 가 뜨는 식. 단 **문자열 안의 `</br>` 는 진짜로 파서를 깨뜨리므로** 이 파일들에서는 `<br>` 을 쓴다(파일 내 관행도 `<br>`).
- 실동작 필수 확인: `060_003=T` 현장 요청→승인→반려→취소 전경로 + `060_003=F` 현장 회귀 없음 + 목록 승인상태/버튼 사용자별 정확성.
